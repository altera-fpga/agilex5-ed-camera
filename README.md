# Camera Solution System Example Designs for Agilex™ 5 Devices

The Camera Solution System Example Designs for Agilex™ 5 Devices demonstrates
practical glass-to-glass camera solutions. The exclusive support for
industry-standard Mobile Industry Processor Interface (MIPI) D-PHY and MIPI
CSI-2 interface on Agilex™ 5 FPGAs provides a powerful tool for camera product
development.
